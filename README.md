# Kiyumi

App móvil (React Native / Expo) que lee tu receta médica y arma automáticamente el horario de tomas — sin que tengas que calcular nada tú.

Kiyumi es la enfermera-zorra que acompaña el proceso: recibe la receta, propone el horario, y celebra cada toma y cada tratamiento completado.

## Estado

En desarrollo temprano. Reemplaza el intento anterior en Unity/Blender ([daniel-llach/kiyomi](https://github.com/daniel-llach/kiyomi), con "o"), que se mantiene como archivo histórico de la exploración 3D.

## Stack

- React Native (Expo)
- Supabase (auth, base de datos, storage)
- Claude (Haiku) para lectura de recetas
